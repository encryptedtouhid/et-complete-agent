# CompleteAgent

Production-grade Microsoft Agent Framework solution generated by the [`et-complete-agent`](https://www.nuget.org/packages/EncryptedTouhid.AgentFramework.Templates) template.

> All projects use the `EncryptedTouhid.<ProjectName>.*` namespace convention. The `EncryptedTouhid.` prefix stays fixed; the rest matches the `-n` value you passed to `dotnet new`.

---

## Run it

```bash
# 1. Pick a provider in src/EncryptedTouhid.CompleteAgent.Host/appsettings.json — Azure OpenAI (default) or OpenAI.

# 2. Set the LLM credential (no secrets in source).
#    Azure OpenAI (DefaultAzureCredential — recommended for prod):
az login
dotnet user-secrets set "Agent:AzureOpenAI:Endpoint" "https://<resource>.openai.azure.com" \
    --project src/EncryptedTouhid.CompleteAgent.Host

#    OpenAI (API key path):
dotnet user-secrets set "Agent:OpenAI:ApiKey" "sk-..." \
    --project src/EncryptedTouhid.CompleteAgent.Host

# 3. Set the API key your callers will pass.
dotnet user-secrets set "Authentication:ApiKey" "$(openssl rand -hex 16)" \
    --project src/EncryptedTouhid.CompleteAgent.Host

# 4. Run.
dotnet run --project src/EncryptedTouhid.CompleteAgent.Host
```

```bash
curl -X POST http://localhost:5000/agent/run \
  -H "X-API-Key: <your-key>" \
  -H "Content-Type: application/json" \
  -d '{"input": "Summarise Clean Architecture in two sentences."}'
```

## Layout

| Project | Responsibility | Depends on |
| --- | --- | --- |
| `EncryptedTouhid.CompleteAgent.Domain` | Contracts and value records — `IAgentRunner`, `AgentRequest`, `AgentResult`, `PromptVersion`. | nothing |
| `EncryptedTouhid.CompleteAgent.Application` | `AgentRunner`, tools, workflows, prompt sanitiser, retry, moderation contracts, RAG contracts. | Domain |
| `EncryptedTouhid.CompleteAgent.Infrastructure` | LLM client factory (Azure OpenAI / OpenAI), EF Core SQLite, Qdrant vector store, Azure Content Safety, log redaction. | Application |
| `EncryptedTouhid.CompleteAgent.Host` | Composition root, HTTP endpoints, JWT + API-key auth, rate limiting, telemetry, cost budget, health checks. | All above |
| `EncryptedTouhid.CompleteAgent.Application.Tests` | xUnit + NSubstitute + `FakeTimeProvider`. **All MIT/Apache — zero commercial libraries.** | Application, Domain, Infrastructure |

## Configuration

All settings live in `appsettings.json`. Override via environment variables prefixed `COMPLETEAGENT_` or via user-secrets in development. Secrets must **never** be committed.

| Section | Keys |
| --- | --- |
| `Agent` | `Provider` (`AzureOpenAI` / `OpenAI`), `Model`, `AzureOpenAI.Endpoint`, `OpenAI.ApiKey` |
| `Authentication` | `ApiKey` (≥ 16 chars) |
| `Jwt` | `Enabled`, `Authority`, `Audience`, `ValidIssuers`, `ClockSkewSeconds` |
| `RateLimit` | `Store` (`InMemory` / `Redis`), `PermitLimit`, `WindowSeconds`, `RedisConnectionString` |
| `CostBudget` | `Enabled`, `DailyTokenLimitPerKey` |
| `Resilience` | `MaxRetryAttempts`, `BackoffSeconds` |
| `Telemetry` | `ServiceName`, `OtlpEndpoint`, `EnableConsoleExporter` |
| `Conversation` | `TtlMinutes`, `MaxMessagesPerConversation` |
| `Persistence` | `ConversationStore` (`InMemory` / `Sqlite` / `SqlServer` / `AzureSql` / `Postgres` / `MySql` / `Cosmos` / `Mongo`), `ConnectionString`, `Cosmos.{ConnectionString,AccountEndpoint,AccountKey,Database,ConversationsContainer,AuditContainer,DatabaseThroughput}`, `Mongo.{Database,ConversationsCollection,AuditCollection}` |
| `Retrieval` | `EmbeddingModel`, `VectorStore` (`InMemory` / `Qdrant`), `Qdrant.{Host,Port,Collection,VectorSize}` |
| `Moderation` | `Provider` (`None` / `AzureContentSafety`), `AzureEndpoint`, `MaxAllowedSeverity` |

Every section is bound with `DataAnnotations` validation and `ValidateOnStart()` — the app refuses to start if a required value is missing.

## Extending

### Add a function tool
```csharp
// src/EncryptedTouhid.CompleteAgent.Application/Tools/WeatherTool.cs
public sealed class WeatherTool
{
    [Description("Returns the current weather for a city.")]
    public Task<string> GetWeatherAsync(string city, CancellationToken ct) => /* ... */;
}
```
1. Register in `ApplicationServiceCollectionExtensions.AddApplication`.
2. Add `AIFunctionFactory.Create(_weatherTool.GetWeatherAsync)` to the `tools` array in `AgentRunner.GetOrCreateAgentAsync`.

### Roll a new prompt version
```
src/EncryptedTouhid.CompleteAgent.Host/Prompts/
  v1/   ← current
  v2/   ← copy, edit, point PromptVersion.V1 → V2 in code
```

### Swap a backing store
- **Conversations** — pick one of:
  - `InMemory` (default, no extra config)
  - `Sqlite` — `ConnectionString="Data Source=completeagent.db"`
  - `SqlServer` / `AzureSql` — `ConnectionString="Server=...;Database=...;..."`
  - `Postgres` — `ConnectionString="Host=...;Username=...;Password=...;Database=..."`
  - `MySql` — `ConnectionString="Server=...;Database=...;Uid=...;Pwd=..."`
  - `Cosmos` — `Cosmos.ConnectionString` *or* `Cosmos.AccountEndpoint` + `Cosmos.AccountKey`; container auto-created with `/conversationId` partition + TTL
  - `Mongo` — `ConnectionString="mongodb://..."`; indexes auto-created (compound + TTL)

  All backends share the same `IConversationStore` contract — implement it to add a custom backing. Audit log (`IAuditLog`) ships with matching impls for each.
- **Vectors**: set `Retrieval:VectorStore=Qdrant` and supply the host/collection, or implement `IDocumentRetriever` for Pinecone / Azure AI Search / PgVector.
- **Moderation**: set `Moderation:Provider=AzureContentSafety` and the endpoint, or implement `IContentModerator`.

## Deploy

### Local — docker-compose
```bash
export OPENAI_API_KEY=sk-...
export API_KEY=$(openssl rand -hex 16)
docker compose up --build
```
The compose stack wires `agent → redis → qdrant → aspire-dashboard` with persistent volumes.

| Service | URL |
| --- | --- |
| Agent API | http://localhost:8080 |
| **Scalar API Explorer** | **http://localhost:8080/scalar** — GitHub-themed, dark/light auto |
| **Aspire Dashboard** | **http://localhost:18888** — traces, metrics, structured logs |
| Qdrant UI | http://localhost:6333/dashboard |

```bash
docker build -t ghcr.io/<your-org>/completeagent:1.0.0 .
docker push ghcr.io/<your-org>/completeagent:1.0.0

# Edit deploy/k8s/secret.example.yaml with real values, or use External Secrets / Key Vault CSI.

```

## Security checklist

- [x] No secrets in source — `appsettings.Development.json`, `secrets.json`, `*.env` all gitignored.
- [x] `DefaultAzureCredential` preferred over API keys.
- [x] API keys compared with `CryptographicOperations.FixedTimeEquals` (timing-attack resistant).
- [x] JWT bearer enforces issuer, audience, and lifetime.
- [x] `InputSanitiser` delimits user content; `OutputGuardrail` scrubs response before return; `IContentModerator` checks both directions.
- [x] `PromptRedactor` scrubs emails, secrets, card numbers from logs.
- [x] Rate limiting + cost budget protect the upstream LLM bill.
- [x] Container runs non-root, read-only FS, all caps dropped, seccomp `RuntimeDefault`.
- [x] `NetworkPolicy` restricts egress to DNS, HTTPS, and known internal services.

## Architecture notes

- **Why Clean Architecture?** It keeps the Domain free of frameworks and SDK types so a Provider swap (Azure OpenAI → OpenAI → Bedrock) touches only Infrastructure, never business logic.
- **Why an `IChatAgentFactory` instead of injecting `IChatClient`?** The Microsoft Agent Framework `AsAIAgent` / `CreateAIAgent` extensions live on the OpenAI `ChatClient`, not on `IChatClient`. The factory hides that detail so Application stays SDK-agnostic.
- **Why source-generated logging and JSON?** Allocation-free at runtime and AOT-friendly when you publish trimmed.
- **Why both API-key and JWT auth?** API key for service-to-service traffic; JWT for user-facing flows behind an identity provider. Both can be enabled together.
